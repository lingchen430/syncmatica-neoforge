# NeoForge 26.1.2 全系列通用版验证记录

版本：0.3.20-neoforge.3。Minecraft 26.1.2，Java 25，Gradle 9.2.1。

## 声明范围

NeoForge `[26.1.2.0-beta,26.1.3)`，覆盖整个 NeoForge 26.1.2 构建系列。Minecraft 仍严格为 26.1.2。
客户端 MaFgLib 下限 0.5.4；.84 之前用 0.5.4，.84 起用 0.5.5 或 0.5.6。服务端不需要客户端前置。

## 本地验证

基于该系列最早的 NeoForge 26.1.2.0-beta 与 MaFgLib 0.5.4 编译成功，5 项检查全部通过：

- 临时专用服务端环境运行、通信上下文和命令初始化。
- Syncmatica 数据包往返读取与重复编码。
- 投影位置、旋转、镜像与所有者元数据保存读取。
- 16 处启用的 Syncmatica 注入签名与目标类文件匹配。
- 所选 MaFgLib 的 ItemStack 提示信息注入方法、调用目标和序号匹配所选 NeoForge。

自动构建矩阵覆盖 .0-beta / 0.5.4、.77 / 0.5.4、.84 / 0.5.5、.122 / 0.5.5、.126 / 0.5.6。
矩阵状态以 GitHub Actions 对应提交的结果为准。
